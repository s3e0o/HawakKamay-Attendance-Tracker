
# 🎓 Hawak Kamay — Attendance Tracker

A web-based attendance tracking system designed to help educational institutions manage student records and organize attendance-related activities through a centralized platform.

## 📖 About the Project

**Hawak Kamay Attendance Tracker** is a school management project developed to support student information management and attendance monitoring.

The system aims to simplify administrative tasks by organizing student records, academic information, and attendance-related processes in one application.

## 🚀 Getting Started

Follow these steps to set up the project locally.

### Prerequisites

- A local PHP development environment, such as [XAMPP](https://www.apachefriends.org/).
- PHP.
- MySQL or MariaDB, if required by the project.
- A web browser.

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/s3e0o/HawakKamay-Attendance-Tracker.git
   ```

2. **Move the project into your local server directory**

   For XAMPP, place the project folder inside:

   ```text
   C:\xampp\htdocs\
   ```

3. **Start the local server**

   Open the XAMPP Control Panel and start Apache and MySQL if your project uses MySQL.

4. **Configure the database**

   Create the required database in phpMyAdmin and import the project's SQL file, if one is included in the repository.

5. **Configure the database connection**

   Update the project's database configuration file with your local database host, database name, username, and password.

6. **Open the application**

   Visit the following address in your browser, replacing the folder name if necessary:

   ```text
   http://localhost/HawakKamay-Attendance-Tracker/
   ```
